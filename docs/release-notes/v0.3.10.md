## LCDiff v0.3.10

Patch release restoring visible feedback while an in-app update is downloading.

### Changes

- Keeps the updater prompt visible after Download and install is selected.
- Shows a disabled Downloading action while the native updater is still running.
- Preserves the existing Restart action after success and GitHub Release fallback after failure.

### Validation

- Regression coverage holds the native download promise pending and verifies that progress feedback remains visible.
- Full frontend build, test, render, branding, and documentation verification gates.
- Rust workspace and Java 17 sidecar release gates.
