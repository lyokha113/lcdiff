## LCDiff v0.3.11

Architecture-standardization release preserving LCDiff's existing product,
wire, archive, sidecar, native-integration, and editor contracts.

### Changes

- Splits the desktop backend into a thin composition root, explicit state,
  event, menu, command, archive-access, and sidecar modules.
- Routes frontend platform access through typed IPC facades and organizes
  application logic by feature-owned workflow controllers.
- Adds executable architecture guards for backend dependency direction,
  frontend ownership, IPC contracts, raw Tauri access, and CI enforcement.
- Keeps confirmed Free Text diff results read-only at both Monaco and DOM
  accessibility boundaries.
- Updates architecture and development documentation to match the implemented
  source layout and validation ladder.

### Compatibility

- Preserves command and event names, serialized DTO shapes, staged atomic save,
  archive cache behavior, nested-archive behavior, Java 17 sidecar engines,
  native menus/open-with integration, Monaco lifecycle, font startup, and
  existing editable/read-only content boundaries.

### Validation

- Full frontend architecture, build, test, render, branding, and documentation
  verification with 410 passing tests.
- Rust formatting and clippy gates plus 125 passing workspace tests.
- Java 17 sidecar smoke covering CFR, Vineflower, JD-Core, JD-Core v0, ASM,
  inner and anonymous classes, and malformed-bytecode fallback.
- Artifact-backed macOS native E2E for View, Compare, Free Text, search,
  staged and signed archive saves, drag/drop, open-with, native menus,
  updater check, Monaco editors, and bundled sidecar resources.
