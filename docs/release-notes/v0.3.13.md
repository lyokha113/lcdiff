## LCDiff v0.3.13

In-app updater feedback release focused on making native update download and
installation progress visible without blocking the diff workspace.

### Changes

- Shows a compact download bar in the StatusBar while a native update downloads.
- Displays percentage and transferred bytes when the updater provides a content
  length, and an indeterminate bar when it does not.
- Changes the status message to `Installing update...` after the download
  completes, before the existing restart action becomes available.
- Shows matching progress feedback in Preferences > Misc > Updates.

### Updater and fallback

- Native updates remain user-triggered and use signed updater artifacts where
  supported by the current package.
- Failed native checks or installs continue to expose the GitHub Releases
  fallback; no update download happens automatically.

### Validation

- Frontend architecture, build, unit/integration tests, render, branding, and
  documentation verification are run before tagging.
- Rust workspace formatting, tests, clippy, and the Java 17 sidecar smoke test
  are run before tagging.
