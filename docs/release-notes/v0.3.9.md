## LCDiff v0.3.9

Patch release improving the first screen for returning archive-inspection work.

### Changes

- Reworked the splash screen around Recent work so reopening a session is the dominant action.
- Shows Compare sources separately with their full paths, accessible Left/Right labels, and direct reopen actions.
- Keeps the five most recent sessions visible at startup and verifies responsive history-first layout behavior.
- Aligns the splash with the app's Light, Dark, and System color preferences while preserving readable contrast.

### Validation

- Component coverage for history hierarchy, reopen labels, expansion, collapse, and empty state.
- Browser render coverage for Light and Dark splash palettes, contrast, five-row visibility, and responsive geometry.
- Full frontend, branding, and documentation verification gates.
